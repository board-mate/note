# 모임 운영 웹앱 v4

모바일에서 카카오톡처럼 빠르게 눌러 쓰는 것을 목표로 만든 로그인 없는 공개형 모임 운영 페이지입니다.


## v4 추가: PC / 모바일 UI 정리

- PC: 상단 고정 메뉴(`홈 / 달력 / 회의록 / 할 일 / 공지`)
- PC: 상단에서 바로 `새 회의록`, `일정` 작성
- 넓은 화면에서 홈 대시보드를 4열 구조로 최적화
- PC 회의록 목록은 화면 폭에 따라 2~4열로 자동 변화
- 태블릿 레이아웃 별도 대응
- 모바일은 기존 하단 5탭 앱 구조 유지
- 모바일 검색창 sticky 처리
- 모바일 카드/달력 그림자와 밀도를 줄여 가독성 개선

## v3부터 포함: 월간 달력

- `달력` 탭 추가
- 회의록의 회의 날짜와 등록 일정을 한 달력에서 함께 표시
- 회의록과 일반 일정을 서로 다른 표시로 구분
- 이전 달 / 오늘 / 다음 달 이동
- 날짜를 누르면 해당 날짜의 회의와 일정 목록 표시
- 달력의 항목을 누르면 해당 회의록/일정 바로 수정
- 선택한 날짜에 바로 새 일정 추가
- 모바일에서는 제목 대신 작은 점/막대로 표시해 한눈에 일정 밀도를 확인


## v2부터 포함된 기능

### 홈 대시보드
- 다음 모임 일정
- 공지사항
- 최근 회의록
- 남은 할 일
- 예정 일정

### 회의록
- 회의록 전체 목록
- 프로젝트/분류 필터
- 검색
- 새 회의록 작성
- 회의 제목 수정
- 카드에서 `제목 수정` 버튼으로 바로 제목 입력란 포커스
- 회의 내용/결정사항/참석자/장소 수정
- Action Item
- 수정 이력
- 휴지통

### 공지사항
- 새 공지
- 수정
- 삭제
- 상단 고정

### 일정
- 새 일정
- 수정
- 삭제
- 가장 가까운 일정은 홈 상단에 표시

### 할 일
- 모든 회의록의 Action Item 통합 보기
- 미완료/전체 전환
- 목록에서 바로 완료 체크
- 회의록으로 이동 가능

## 질문하신 부분

**회의록 목록을 볼 수 있습니다.**
모바일 하단의 `회의록` 메뉴에서 전체 목록을 확인합니다.

**회의 제목도 수정할 수 있습니다.**
회의록을 열고 `회의 제목`을 수정한 뒤 저장하면 됩니다.
또한 목록 카드의 `제목 수정`을 누르면 제목 입력칸으로 바로 이동합니다.

## 미리보기
`index.html`을 열면 localStorage 기반 미리보기로 동작합니다.
이 상태는 한 기기에서만 보입니다.

## 여러 사람이 같이 쓰려면

1. Supabase 프로젝트 생성
2. `schema.sql` 실행
3. `config.js`에 Project URL과 publishable/anon key 입력
4. 폴더 전체를 정적 호스팅에 배포

예: GitHub Pages / Netlify / Vercel / Cloudflare Pages

> 브라우저 코드에는 `service_role` 키를 넣지 마세요.

## v5 추가 기능
- 대한민국 공휴일/대체공휴일 달력 표시 (고정 공휴일 + 음력 설/추석/부처님오신날 + 2026년 노동절·제헌절 + 최근 선거/임시공휴일)

- 일반 게시판 CRUD (Supabase `posts` 테이블 / 미리보기 localStorage 지원)

기존 Supabase를 사용 중이라면 배포 전에 최신 `schema.sql`을 SQL Editor에서 다시 실행해 `posts` 테이블과 정책을 추가하세요.

### 공휴일 기준
현행 「관공서의 공휴일에 관한 규정」을 기준으로 표시합니다. 2026년부터 노동절(5월 1일)과 제헌절(7월 17일)을 반영했으며, 2026년 6월 3일 제9회 전국동시지방선거도 포함했습니다. 정부가 수시 지정하는 향후 임시공휴일과 새 선거일은 `app.js`의 `special` 목록에 추가하면 됩니다.
